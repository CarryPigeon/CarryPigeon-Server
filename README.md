# CarryPigeon Backend

> 面向小社区与特定场景的自部署 IM 内核：**最小核心、明确约束、插件扩展**。

CarryPigeon Backend 是一个基于 **Java 25 + Spring Boot** 的开源聊天后端。它不是 QQ/微信式的通用 IM，也不是开箱即用的完整产品；核心只保留频道聊天的最小闭环，差异化能力由插件补齐。

## 适合谁

- 想自己部署、自己掌控数据的小社区、兴趣组、内部团队。
- 有特定消息类型或外部服务需求，愿意写插件的人。
- 想要一个 Java/Spring 底座，而不是一整套不可改的 IM 平台。

## 主要特性

- 可拔插的外部服务
- 高度可定制的消息类型
- 面向拓展到插件系统

## 模块结构

- `application-starter`：启动与运行时装配模块
- `chat-application`：核心业务域模块
- `infrastructure-basic`：固定全局基础设施模块
- `infrastructure-service`：可拔插外部服务基础设施父模块
  - 各级子模块承当具体的外部服务功能
- `distribution`：当前 thin jar + libs 打包与分发模块

## 当前边界说明

- 当前项目仍处于迭代期，不应默认视为生产级稳定发行版
- Docker 当前只承接外部依赖，不承接应用容器化（由于插件化性质决定）
- 当前部署手册不覆盖 Kubernetes、多节点高可用或生产级进程托管方案由部署方自行优化实现
