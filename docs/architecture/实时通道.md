# 实时通道

## 1. 契约侧：`infrastructure-basic/realtime`

```text
realtime
├── RealtimeFrameCodec.java          四键 envelope 编解码 + 协议字面量常量（@Component）
├── RealtimeProtocolException.java   协议违规（带稳定 reason，不依赖任何 feature 码表）
├── downlink/
│   ├── RealtimeEventApi.java        业务侧唯一发布入口
│   ├── RealtimeEvent.java           事件：类型 + 载荷 + 接收账号
│   ├── RealtimeEventType.java       线上事件名（正则校验）
│   └── RealtimeFrame.java           Event / Ack / CommandError 三种下行帧
└── uplink/
    ├── RealtimeClientMessage.java   上行 envelope 与通用字段读取
    ├── RealtimeCommandHandler.java  命令契约（插件可实现）
    └── RealtimeCommandContext.java  命令上下文契约
```
## 2. 连接与认证时序

| 阶段 | 行为 |
|---|---|
| 握手前 | `RealtimeChannelSession` 从握手请求写入 requestId/traceId/route，建立通道属性 |
| 握手完成 | 分配 sessionId，登记首帧认证超时（`authentication-timeout-seconds`，默认 10s） |
| 首帧 `auth` | 校验 access token → 绑定 `CpPrincipal` → 取消超时 → 登记 token 过期定时 → 回 `auth.ok` → 按锚点回放 |
| 已认证再发 `auth` | 拒绝：`already_authenticated`，提示改用 `reauth` |
| `reauth` | 允许换主体；主体变化时先从旧账号索引摘除再注册新账号 |
| 空闲 | `read-idle-timeout-seconds`（默认 60s）无入站数据 → `idle_timeout` 错误帧并关闭 |
| token 过期 | 定时触发 → `token_expired` 错误帧并关闭 |
| 断连 | 取消两个定时任务，把通道从在线索引摘除 |

认证失败统一抛 `features.auth.domain.problem.AuthProblem` 的 401 类码，由分派层转成 `unauthorized` / `token_expired`。

## 3. 断线续传

| 项 | 语义 |
|---|---|
| 窗口结构 | `accountId → 最近 N 条事件帧`，只在内存 |
| 容量配置 | `event-retention`（默认 1h）、`max-events-per-account`（默认 1000）、`max-event-accounts`（默认 10000） |
| 账号数达上限 | 只回收"事件已全部过期"的账号；回收后仍无空位则不建档，该账号退化为 HTTP 全量同步，**已有窗口不受影响** |
| 锚点命中 | 返回锚点之后的事件，逐条写出 |
| 锚点不存在/已淘汰 | 下发 `resume.failed`，`data.reason = event_too_old`，客户端改走 HTTP 全量同步 |
| 无锚点 | 不回放 |
| 进程重启 | 窗口全部丢失，客户端必然走全量同步（设计如此） |

## 4. 配置项

| 键 | 默认 | 作用 |
|---|---|---|
| `cp.chat.server.realtime.enabled` | `true` | 是否启动 Netty 监听；关闭时服务发现返回 `wsUrl=null` |
| `cp.chat.server.realtime.host` / `port` / `path` | `127.0.0.1` / `18080` / `/api/ws` | 监听地址与握手路径 |
| `cp.chat.server.realtime.boss-threads` / `worker-threads` | `1` / `0` | `0` 表示用 Netty 默认 |
| `cp.chat.server.realtime.authentication-timeout-seconds` | `10` | 首帧认证时限 |
| `cp.chat.server.realtime.read-idle-timeout-seconds` | `60` | 读空闲关闭 |
| `cp.chat.server.realtime.event-retention` | `1h` | 续传窗口保留时间 |
| `cp.chat.server.realtime.max-event-accounts` | `10000` | 建窗口的账号上限 |
| `cp.chat.server.realtime.max-events-per-account` | `1000` | 单账号事件条数上限 |
| `cp.chat.server.realtime.max-payload-bytes` | `262144` | 单帧 UTF-8 字节上限 |
