# 配置约定

**状态：草稿（待评审）**
**读者：** 新增配置项、排查配置不生效、写部署覆盖的开发者
**边界：** 本文说明配置的命名、归属、绑定方式与覆盖方式。实际默认值以 `application-starter/src/main/resources/application.yaml` 为准。

---

## 1. 命名与归属

| 规则 | 说明 |
|---|---|
| 项目自定义前缀 | `cp` |
| 分段 | `cp.<模块/域>.<子域>.<项>`，如 `cp.chat.server.realtime.max-payload-bytes` |
| 归属 | 配置由**实际消费它的模块**持有：实时通道 → `config/ws`，对象存储 → `storage-impl`，ID → `infrastructure-basic` |
| Spring 标准前缀 | 数据库、Redis、邮件、multipart 沿用 `spring.*`，不搬到 `cp.*` |

禁止为了"集中管理"把所有配置塞进同一个通用配置类；也禁止在 `infrastructure-basic` 里放业务配置。

---

## 2. 绑定方式（当前唯一推荐）

```java
@ConfigurationProperties(prefix = "cp.chat.server.realtime")
public record RealtimeServerProperties(boolean enabled, String host, ...) { ... }
```

- **不可变记录 + `@ConfigurationProperties`**，通过启动类上的 `@ConfigurationPropertiesScan(basePackages = {"team.carrypigeon.backend"})` 注册。
- **不要**在配置记录上标 `@Component`：组件扫描会把它当普通 Bean 去注入构造参数，绑定会失败（已实证：`No qualifying bean of type 'boolean'`）。
- **不要**为新配置再写 `@Configuration` + `@Bean` 装配类。
- 记录内的校验放在紧凑构造器里（如 `port` 范围、`path` 必须以 `/` 开头）；非法值在绑定期失败，不要留到运行期。

例外只有一个：装配第三方类型（`MinioClient`、`OkHttpClient` 这类不是我们定义的类）时，才在 `*-impl` 写 `@AutoConfiguration` + `@Bean`。这类对象无法标 `@Component`，当前只有 `storage-impl` 属于这种情形。

---

## 3. Bean 与开关

| 场景 | 做法 |
|---|---|
| 普通组件 | 实现类标 `@Component` |
| 按配置开关的组件 | `@Component` + `@ConditionalOnProperty(prefix = "cp.infrastructure.service.database", name = "enabled", havingValue = "true", matchIfMissing = true)`（例：`database-impl` 的全部 `MybatisPlus*DatabaseService`） |
| Mapper 接口 | 由启动类 `@MapperScan` 扫描，不写 `@Configuration` |
| 需要按条件装配第三方对象 | 模块内 `@AutoConfiguration`（当前只有 `storage-impl`） |

`@ConditionalOnMissingBean` 只对 `@Bean` 有效；`@Component` 装配的组件不再具备"外部可覆盖"语义，需要替换实现时直接改模块。

## 5. 覆盖方式与优先级

| 方式 | 用途 |
|---|---|
| `application-starter/src/main/resources/application.yaml` | 仓库内默认值 |
| 分发目录 `config/application.yaml` | 部署环境覆盖（随分发产物发布，见 `docs/operations/部署手册.md`） |
| 环境变量 / JVM 属性 | 容器或临时覆盖，优先级最高 |

规则：

- 生产必须覆盖：数据库账号密码、JWT 密钥、`share-key.secret`、MinIO 凭据、`cp.chat.server.id`、`cp.local-dev.*`（保持关闭）。
- 本地默认值只用于开发，不得作为生产默认值写进代码。
- 改默认值必须同时改本文 §4 与受影响的部署文档。
